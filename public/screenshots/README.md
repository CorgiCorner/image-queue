# Gallery example images

The gallery and preview screenshots show 12 AI-generated variations made for this project. Visual references and short descriptions were selected from [Ricardo Matos on Lummi](https://www.lummi.ai/creator/ricardomatos). Colors, finishes or scene details were changed before generation. These are generated variations, not original Lummi downloads.

Reference originals are not distributed with the application. Local generation records retain source URLs, descriptions, changes and submitted prompts.
